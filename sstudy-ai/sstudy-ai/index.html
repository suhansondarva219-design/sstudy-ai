ABOUT SSTUDY

Learning made simpler.

SSTUDY.com is a student learning website prototype for exploring school subjects and practising quiz questions.

What this version can do

✔ Ask a real AI study assistant
✔ Run a quiz and calculate your score
✔ Choose English, Hindi, or Gujarati answers
✔ Work on phones and computers

What is not included yet

Student accounts, cloud-saved results, and a teacher admin panel are not included yet. AI answers require a securely configured Gemini API key on the hosting server.
